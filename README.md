# A/B-тест алгоритма рекомендаций: анализ асимметричного влияния

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/websterdable/ab-test-recommendations/blob/main/ab_test_analysis.ipynb)

## О проекте

Анализ A/B-теста нового алгоритма рекомендаций (B) против старого (A) на стриминговой платформе. Ключевая метрика — **общее время просмотра на пользователя (в минутах)**.

Особенность задачи: распределение метрики имеет **длинный правый хвост** (немного пассивных зрителей и небольшая группа «супер-зрителей»), из-за чего классические параметрические тесты (t-тест) некорректны, а стандартные метрики среднего вводят в заблуждение.

## Данные

- **10 000 пользователей**, по 5 000 в каждой группе (A / B)
- Две недели тестирования
- Колонки: `user_id`, `group` (A/B), `total_watch_time_min`

## Методы

1. **Описательная статистика** по группам (mean, std, перцентили)
2. **U-тест Манна-Уитни** (двусторонний + односторонний) — непараметрический тест для сравнения распределений
3. **Анализ перцентилей** (75-й, 90-й, 95-й) — для выявления асимметричного эффекта в хвостах распределения
4. **Визуализация** разницы между группами по сегментам

## Ключевые результаты

| Перцентиль | Группа A | Группа B | Прирост    |
|------------|---------:|---------:|--------:   |
| 75-й       | 44.9 мин | 46.4 мин | **+3.1%**  |
| 90-й       | 71.5 мин | 76.2 мин | **+6.6%**  |
| 95-й       | 119.3 мин| 153.6 мин| **+28.7%** |

- **U-тест Манна-Уитни (двусторонний):** p-value = 0.045 → различия статистически значимы
- **U-тест (односторонний, B > A):** p-value = 0.023 → группа B показывает бо́льшие значения

## Выводы

1. **Алгоритм B эффективен** — статистически значимо увеличивает время просмотра.
2. **Эффект асимметричен:** чем активнее пользователь, тем больше прирост. Максимум — у топ-5% «супер-зрителей» (+28.7%).
3. **U-тест Манна-Уитни** фиксирует факт различия, но **не показывает, где именно** происходит эффект.
4. **Анализ перцентилей** оказался самым информативным методом — он вскрыл асимметричную природу влияния и позволил оценить эффект по сегментам.
5. **Рекомендация:** запускать алгоритм B на всю аудиторию, но **поэтапно**, с мониторингом оттока и удовлетворённости (метрики вовлечённости могут не отражать риски для пассивных пользователей).
